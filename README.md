# fileMORDAinh

Локальная медиатека для видео, аудио и обычных файлов.

## Возможности

- просмотр видео, аудио и файлов;
- скачивание файлов без входа;
- загрузка больших файлов частями;
- категории;
- сортировка по просмотрам, длительности и дате;
- автоматическое определение длительности видео;
- JPEG-превью видео через OpenCV;
- SQLite без отдельного сервера;
- админ-режим с паролем;
- безопасная первичная настройка через одноразовый код;
- production-запуск через Waitress вместо Flask development server.

## Требования для macOS

- macOS 12+;
- Python 3.10+;
- Safari, Chrome или Firefox;
- Apple Silicon (M1–M5) или Intel.

OpenCV используется как `opencv-python-headless`, поэтому отдельный GUI OpenCV не нужен.

## Быстрый запуск

Клонирование и установка:

```bash
git clone https://github.com/tranzistrina/fileMORDAinh.git
cd fileMORDAinh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python index.py
```

Сервер запускается на:

```
http://127.0.0.1:1313
```

Но теперь сервер по умолчанию слушает `0.0.0.0`, поэтому к нему можно подключаться с других устройств по IP Mac:

```
http://IP_ТВОЕГО_MAC:1313
```

### Запуск после первой установки

```bash
cd fileMORDAinh
source .venv/bin/activate
python index.py
```

Или одним скриптом:

```bash
chmod +x run_mac.sh
./run_mac.sh
```

### Другой порт

```bash
PORT=6767 python index.py
```

### Явно указать адрес

```bash
HOST=0.0.0.0 PORT=1313 python index.py
```

### Запуск с большим числом worker threads

```bash
WAITRESS_THREADS=16 python index.py
```

## Первый запуск и пароль

При первом старте сервер создаёт одноразовый код первичной настройки и печатает его в терминал:

```
[SECURITY] First-run setup code: ...
```

Откройте сайт. Вместо медиатеки появится форма первичной настройки.

Введите:

1. код из терминала;
2. пароль администратора;
3. повтор пароля.

После создания администратора код удаляется и больше не действует.

Пароль хранится не в открытом виде, а в виде хэша в SQLite.

## Права доступа

Гость без входа может:

- просматривать библиотеку;
- открывать файлы;
- смотреть видео и слушать аудио;
- скачивать файлы.

Только администратор после входа может:

- загружать файлы;
- менять название и описание;
- менять категории;
- создавать категории;
- менять превью видео;
- сканировать папку `uploads`.

Прямые POST-запросы к операциям записи также требуют авторизации, поэтому просто открыть URL недостаточно.

## Доступ из локальной сети

На Mac найдите локальный IP:

```bash
ipconfig getifaddr en0
```

Если Mac подключён через другой интерфейс, можно посмотреть адреса командой:

```bash
ifconfig
```

После этого другой компьютер в той же сети открывает:

```
http://IP_ТВОЕГО_MAC:1313
```

macOS может показать запрос на разрешение входящих подключений для Python. Разрешите его, если хотите доступ по локальной сети.

## Доступ из интернета

Само приложение теперь слушает `0.0.0.0`, но это не означает, что интернет автоматически умеет находить твой Mac. Для доступа извне дополнительно потребуется:

1. проброс порта на роутере на локальный IP Mac;
2. разрешение входящего соединения в macOS Firewall;
3. желательно HTTPS через reverse proxy/VPN.

Не публикуй такой сервис в интернет без HTTPS: пароль и сессия должны передаваться через защищённое соединение.

Для reverse proxy можно оставить Waitress на локальном порту, например:

```bash
HOST=127.0.0.1 PORT=1313 python index.py
```

а внешний HTTPS завернуть через nginx, Caddy или другой reverse proxy.

## Переменные окружения

`HOST`
: адрес привязки. По умолчанию `0.0.0.0`.

`PORT`
: HTTP-порт. По умолчанию `1313`.

`WAITRESS_THREADS`
: количество рабочих потоков Waitress. По умолчанию `8`.

`SESSION_SECRET`
: необязательный фиксированный секрет Flask-сессии. Если не задан, приложение создаёт локальный файл `.session_secret`.

`COOKIE_SECURE`
: установите `1`, если приложение доступно только через HTTPS.

`ADMIN_SETUP_CODE`
: необязательный заранее заданный код первой настройки. Если не задан, код генерируется случайно и выводится в терминал.

```bash

python -m pip install --upgrade -r requirements.txt

```

- `.session_secret`
- `.setup_code`
- `.venv/`

## Приватные файлы

Категория `privat` является специальной закрытой категорией.

Если файл имеет категорию `privat` (регистр не важен), он автоматически считается приватным. Для обычного посетителя такой файл:

- не показывается в главном списке;
- не показывается в публичном списке категорий;
- не открывается по прямой ссылке;
- недоступен для просмотра видео/аудио;
- недоступен для скачивания;
- недоступен даже через прямой URL к превью.

Администратор видит и открывает такие файлы без ограничений.

При назначении `privat` вместе с другими категориями файл всё равно остаётся приватным. Чтобы снова сделать его публичным, администратор должен убрать категорию `privat`.
